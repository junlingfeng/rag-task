# Technical Specification Supplement - Beijing Branch

## Design and Review

Beijing Branch implementation: Interface designs must be submitted as a specification and peer reviewed. Cross-domain calls additionally require capacity assessment and failure impact analysis. This supplement is effective from version 2021.

## Change Management

Beijing Branch implementation: Interface changes require Architecture Review Board approval and advance notice. Breaking changes must ship as a new version with a transition period and must not silently alter existing semantics. This supplement is effective from version 2021.

## Testing and Acceptance

Beijing Branch implementation: Before release, APIs must pass contract tests, exception-path tests and load tests with a published report. APIs that fail acceptance must not be exposed to consumers. This supplement is effective from version 2021.
